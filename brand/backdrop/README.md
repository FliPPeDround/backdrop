# Backdrop — Logo

小程序「Backdrop」品牌标识。核心意象:**内容背后的那一层**——一枚 -10° 倾斜的描边取景框,框住一层自左上向右下渐隐至透明的背景层。渐隐即「退到背后去」这件事本身。

标形直接由界面里的 `.brand-mark` CSS 翻译而来,几何与 UI 保持 1:1。

## 文件

| 文件                                    | 用途                                     |
| --------------------------------------- | ---------------------------------------- |
| `icon-dark.svg` / `-1024/-512/-144.png` | 主图标(深色砖),小程序头像、任何背景通用  |
| `mark-white.svg`                        | 透明母版,**仅限深底**:水印、加载态、页头 |
| `lockup-horizontal.svg` / `.png`        | 横版组合标识(页头、文档)                 |
| `lockup-vertical.svg` / `.png`          | 竖版组合标识(启动页、社交)               |

## 配色

- 砖底 / 深色 `#0A0A0A`
- 描边 `#FFFFFF` @ 95%
- 背景层 `#FFFFFF`,145° 由 100% 渐隐至 12%
- 字标 `#0A0A0A`(浅底 lockup 内)

## 母版几何

512 视口,标形以 CSS 单位定义后 `scale(8.2)`,绕盒中心 `rotate(-10)`。

- 外框 border-box **26×29**(小程序端 `presetApplet` 不带 preflight,`view` 是 content-box:23+3 × 26+3)
- 描边 1.5px → SVG 用中心线矩形 `24.5×27.5`,`rx 5.25`(等价 CSS 外沿圆角 6px)
- 内层 `13×16 rx 3`,四边到框内侧均为 5px
- 渐变 `objectBoundingBox`:`x1=.046 y1=-.026 → x2=.954 y2=1.026`(渐变线长 20.563,端点略出盒外,与 CSS 一致)

改任一处需同步 `icon-dark.svg` / `mark-white.svg` / `Logo.vue` / `favicon.svg` / 两个 lockup。

### 各端接线差异

- **Web 页头 `Logo.vue`**:用透明母版(不带砖),`viewBox` 收紧到 `112 112 288 288`——标形旋转后实际外框只有 512 空间的 53%,不收紧的话 `text-26px` 只会画出约 14px 的小标。页头底面是 `App.vue` 里写死的 `#7B7481` 中灰紫,恒定不变,所以白标可成立;**若将来页头背景改为跟随图案,这里必须回退到带深色砖的版本**。
- **`favicon.svg`**:透明版,`viewBox` 同样收紧到 `112 112 288 288`。代价是**浅色标签栏下完全不可见**(白标叠白底),只有深色主题浏览器里成立。需要跨主题可见就换回 `icon-dark-144.png` 那类带深色砖的图。

## 使用限制

- **标形不能放在浅底上**:它是白色渐隐图形,浅底会直接消失。浅底场景一律用带深色砖的 `icon-dark` 或 lockup。
- **最小 64px**。倾斜与渐隐在 48px 以下开始糊,32px 只剩一个白点;`favicon` 属于已知的妥协。
- 不拉伸、不改色、不去掉倾斜、不把渐隐改成实心。

## 小程序头像上传

微信后台「小程序信息 → 头像」上传 `icon-dark-144.png`(或 `-1024`)。必须用深色砖版:微信资料页是浅底,透明母版会看不见。

## 导出

仓库内无 SVG 栅格器(无 rsvg / inkscape / imagemagick),PNG 由临时目录里的一次性 `sharp` 安装生成。字体为 Inter / 系统无衬线,导出依赖本机字体。

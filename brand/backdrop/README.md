# Backdrop — Logo

小程序「Backdrop」品牌标识。核心意象:**内容背后的那一层**——实心背景层从左上露出,前景为描边取景框。黑白灰纯色,无渐变。

## 文件

| 文件                                     | 用途                                   |
| ---------------------------------------- | -------------------------------------- |
| `icon-light.svg` / `-1024/-512/-144.png` | 浅底图标(小程序头像主用)               |
| `icon-dark.svg` / `-1024/-512/-144.png`  | 深底图标                               |
| `mark-mono.svg` / `mark-white.svg`       | 透明单色母版(深/浅底通用,水印、加载态) |
| `lockup-horizontal.svg` / `.png`         | 横版组合标识(页头、文档)               |
| `lockup-vertical.svg` / `.png`           | 竖版组合标识(启动页、社交)             |

## 配色

- 黑 `#0A0A0A`
- 浅底 `#F4F4F5`
- 白 `#FFFFFF`
- 单色使用:纯黑或纯白,不引入其他色

## 小程序头像上传

微信后台「小程序信息 → 头像」上传 `icon-light-144.png`(或 `-1024`),正方形 PNG 即可。

## 安全边距与最小尺寸

- 四周留白 ≥ 图标高度的 1/4。
- 图标最小建议 32px;低于此用简化实心版或提高对比。
- 不拉伸、不改色、不加阴影/描边等特效。

## 母版说明

所有变体共用同一套几何(512 视口 + 蒙版镂空),改一处即可同步浅底/深底/单色。字体为 Inter / 系统无衬线,导出 PNG 依赖本机字体。
